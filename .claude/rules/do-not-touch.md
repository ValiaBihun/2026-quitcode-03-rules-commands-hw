# Захищені зони

## Контекст

`app/src/core/` належить платформній команді: той самий core працює в усіх
клієнтських воркерах агенції, і зміни в ньому йдуть окремим PR через рев'ю цієї
команди. `app/scripts/`, `materials/`, `.coderabbit.yaml` і `.github/` — це умови
задачі, а не робочий код. Це правило діє в **кожній** сесії, незалежно від того,
які файли відкриті.

## Правило

**Не створюй, не редагуй і не видаляй** файли за цими шляхами:

- `app/src/core/**` — ядро платформи
- `app/scripts/**` — перевірка правил, зокрема `check-rules.mjs` і `core.lock.json`
- `materials/**` — вхідні матеріали завдання
- `.coderabbit.yaml`, `.github/**` — конфігурація рев'ю і шаблон PR

**Винятків немає.** Формулювань «можна, якщо задача цього потребує» тут навмисно
нема: будь-яка задача оголосить, що потребує.

### Що робити замість цього

Якщо задача без зміни в захищеній зоні не виконується — **зупинись, не редагуй**
і поверни людині:

1. яка саме задача впирається в захищену зону;
2. який конкретно файл і яка зміна потрібні (напр. «додати необов'язкове поле
   `utmCampaign?: string` до `Lead` у `app/src/core/types.ts`»);
3. чому обійти це в `integrations/` або `sync/` не вийшло;
4. що можна зробити **вже зараз**, не торкаючись захищеної зони, — і чекай на
   підтвердження людини, перш ніж щось міняти.

Часткова робота з чесно названим блокером тут краща за «я обійшов обмеження».

### Окремо про перевірку

`app/scripts/core.lock.json` — це хеші ядра, якими `check:rules` ловить зміну в
core. **Не перегенеровуй його** (`npm run check:rules -- --write-lock` —
заборонено) і не правь вручну: це не виправлення порушення, а його приховування.
Так само не редагуй `check-rules.mjs`, щоб перевірка «проходила».

## Як перевірити

- `cd app && npm run check:rules` → рядок `core-untouched   0`.
- `git status --short` після будь-якої задачі — жодного рядка, що починається з
  `app/src/core/`, `app/scripts/`, `materials/`, `.github/` або `.coderabbit.yaml`.
- `git diff --stat -- app/src/core app/scripts materials .github .coderabbit.yaml`
  → порожньо.
